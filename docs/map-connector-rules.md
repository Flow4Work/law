# 지도 연결선 규칙

- **가운데 정렬:** 부모 카드 중앙과 같은 높이의 경로를 직선 우선으로 두고, 다른 경우의 수를 위·아래로 배치한다. 짝수 분기는 가운데를 기준으로 대칭 배치한다.
- **위쪽 정렬:** 첫 번째 자식 카드로 수평 직선을 먼저 연결하고 나머지 자식은 아래로 분기한다.
- **공통 선:** 같은 부모·Depth 구간의 수평 줄기와 수직 분기 줄기는 한 번만 렌더링한다. 선택한 경로의 강조선은 공통 구간을 재차 전체 경로로 덧그리지 않는다.
- **강조:** 공통 줄기 중 선택된 구간과 선택된 자식으로 가는 선만 빨갛게, 나머지는 중립색으로 표시한다.
- **안전 간격:** 연결선은 카드 영역을 관통하지 않으며, 별개 부모의 분기는 각자 지정된 gutter lane을 사용한다.
- **가변 분기:** 1개·2개·3개·4개 이상의 실제 연결 수에 맞춰 동적으로 생성하며 고정 개수를 가정하지 않는다.
- **회귀 검증:** 가운데/위쪽 정렬, 분기 수, 경로 선택/해제, 카드 충돌, 공통 줄기 중복 여부를 확인한다.
