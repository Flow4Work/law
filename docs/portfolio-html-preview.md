# 포트폴리오용 실제 데스크톱 UI 재생

`http://localhost:3700/?capture=portfolio`는 기존 CIVIL_DEMO와 실제 Canvas·DetailPanel을 사용한다. 준비된 절차를 AI 응답 대기 없이 펼치며, 대화·테마·정렬 등 사용자 저장 상태는 덮어쓰지 않는다. 예시 탭은 데이터를, 새로고침은 카메라까지 초기화한다.

최종 포트폴리오는 KOL Scout와 같은 HTML·CSS 재생 방식이다. 실제 데스크톱의 일곱 상태에서 main.app-shell DOM과 실제 layout.css·page.css를 보존했다. 카드·문구·기간·연결선·상세 패널·지도 좌표를 유지한다. 동영상, 플레이어, 모바일 캡처, 별도 강조 박스는 사용하지 않는다.

- assets/law-desktop-demo.html: 실제 DOM 상태와 재생 순서
- assets/law-desktop-ui.css: 원본 서비스의 실제 스타일
- 절차: 현재 상황과 방법 비교, 지급명령 선택, 절차 세 개 확장
- 기간: 전체 예상 기간, 첫 단계, 이의 여부 단계의 법정 기한
- 갈림길: 방법 선택, 절차 확장, 두 결과와 해당 경로 선택

내부 화면은 1280×720 데스크톱으로 고정한다. 지도는 x=64, y=110의 856×554 영역, 기간은 우측 상세 x=920, y=0의 360×320 영역이다. 좁은 포트폴리오에서도 내부를 모바일로 전환하지 않고 데스크톱 영역을 비례 축소한다. 각 설명 아래에 세로로 배치한다.

부모 페이지는 law:play/law:pause 메시지를 보낸다. 화면 밖·스크롤 중·탭 비활성·동작 줄이기 설정에서는 멈춘다. 자료가 포트폴리오 assets에 있으므로 3700 서버가 꺼져도 표시된다. 일반 서비스 화면과 포트폴리오 03 이외의 섹션은 이 재생으로 대체하지 않는다.
